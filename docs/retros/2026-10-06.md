### 1. Tests never gate anything (Automated checks)

**Evidence**
- `ci.yml` runs `lint`, `typecheck`, and `build`. No job runs tests. Root `package.json` and `turbo.json` have no `test` task, and `apps/desktop` has no `test` script. The agent ran `npx vitest run` by hand.

- `voice-sidecar` pytest has a failure that stays red: `tests/test_pipeline.py::test_vocab_swap_changes_match_target` failed at 2026-10-03T22:55:49Z (`WrBEgP`). The agent spent `KeXXBD` on a `git stash` round-trip to prove the failure predated its change. It still fails today (re-run 2026-10-06, `1 failed, 14 passed, 4 skipped`).
- Three releases (v1.29.5–7) shipped with tests verified only by the agent's own discipline.

**Proposal**
1. Add `"test": "vitest run"` to `apps/desktop/package.json`, a `test` task to `turbo.json`, and a root `"test": "turbo run test"`.
2. Add a `Test` job to `ci.yml` that runs `bun run test`, plus `pytest` for `apps/desktop/voice-sidecar`. Fix or `xfail` `test_vocab_swap_changes_match_target` first.
3. Add a root `"check": "bun run lint && bun run typecheck && bun run test"` so verification is one command (see #4).
